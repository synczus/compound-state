## Updating the Board
When you start working on an item:
- Change its Status from `⚪ Ready` / `🟡 Pending` → `🟡 In Progress`
- Do this before taking any action

When you finish an item:
- Change Status to `✅ Done`
- Add to the `✅ COMPLETED` section at the bottom

## Status Legend
- ⚪ Ready — not started, available
- 🟡 Pending / In Progress — someone's working it
- ✅ Done — completed
- 🔴 Needs exec — requires terminal/Chase to run a command

## Rules
- Do not pick up items from another agent's lane
- If blocked >15 min, surface it in the group chat
- Update the board before your next response
